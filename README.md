# 🛡️ MSHIELD - Lightweight Phishing & URL Scanner

**MSHIELD** is a powerful, lightweight security tool developed for cybersecurity students and professionals. It helps in detecting phishing attempts and malicious URLs using a hybrid analysis approach.

## 🚀 Features
- **Heuristic Logic Scan:** Detects social engineering patterns, urgency, and common phishing keywords.
- **Domain Intelligence:** Identifies suspicious TLDs (like .xyz, .top, .info) and domain squatting patterns.
- **URL Shortener Detection:** Flags links hidden behind bit.ly, t.co, and tinyurl.
- **VirusTotal Integration:** Cross-references URLs with 70+ global security engines via API.
- **Professional UI:** Beautifully formatted reports in the terminal.
